**Raumplaner zum Einbetten.** Kunden planen ihren Raum maßgenau mit euren Produkten – in 2D, 3D und beim Begehen – und schicken das Ergebnis als Warenkorb oder Anfrage an euch.

- **Planer:** eingebunden mit zwei Zeilen Code auf eurer Website
- **Studio:** Katalog pflegen, 3D-Modelle aus Fotos oder Maßen erzeugen
- **Übergabe:** Warenkorb, Angebot als PDF, neutrales Leistungsverzeichnis
